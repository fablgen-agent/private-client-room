# Security policy

Do not place vulnerabilities, credentials, access tokens, private messages,
personal data, server addresses, or recovery keys in a public issue.

For a sensitive deployment concern, email `accounts@enby.fish` with a minimal
description and no secret material. We will arrange a safer exchange only if it
is needed.

The deployment service is configuration and operations work, not a security
audit or penetration test. Upstream Matrix and Element vulnerabilities should
also follow the relevant upstream disclosure policy.
